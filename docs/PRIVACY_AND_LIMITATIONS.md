# 隐私、安全与局限

系统只查询获得授权的网关管理页面和 API。禁止暴力登录、验证码绕过、漏洞利用、ARP 欺骗、DNS 劫持、TLS 解密、无线注入、解除认证、干扰或强制断网。系统不抓取数据包正文、访问网页、聊天内容、账号或 DNS 域名。

持久化前完整 MAC 通过本机随机密钥执行 HMAC-SHA256，普通页面不显示完整 MAC。IP 仅在识别监测电脑时使用，普通客户端 IP 不持久化。日志采用统一脱敏器。默认保留 72 小时。

一台电脑的一块 Wi‑Fi 网卡只能顺序轮询，因此瞬时行为可能漏检。移动数据、离线设备和不产生网关可见数据的 HDMI 活动不可判断。系统不基于 OUI 猜测人员身份。

电脑本地模式仅使用一次性 ICMP、ARP 邻居缓存和 SSDP/UPnP 服务广播。它不执行端口扫描，不获取设备描述正文，不持久化 IP、完整 MAC、USN 或 LOCATION URL。AP 客户端隔离会让该模式漏掉其他设备；媒体服务广播只证明局域网可见，不证明电视亮屏或播放。
