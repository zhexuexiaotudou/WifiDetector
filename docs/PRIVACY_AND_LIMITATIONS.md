# 隐私、安全与局限

系统只查询获得授权的网关管理页面和 API。禁止暴力登录、验证码绕过、漏洞利用、ARP 欺骗、DNS 劫持、TLS 解密、无线注入、解除认证、干扰或强制断网。系统不抓取数据包正文、访问网页、聊天内容、账号或 DNS 域名。

持久化前完整 MAC 通过本机随机密钥执行 HMAC-SHA256，普通页面不显示完整 MAC。IP 仅在识别监测电脑时使用，普通客户端 IP 不持久化。日志采用统一脱敏器。默认保留 72 小时。

一台电脑的一块 Wi‑Fi 网卡只能顺序轮询，因此瞬时行为可能漏检。移动数据、离线设备和不产生网关可见数据的 HDMI 活动不可判断。系统不基于 OUI 猜测人员身份。

电脑本地模式仅使用一次性 ICMP、ARP 邻居缓存和 SSDP/UPnP 服务广播。它不执行端口扫描，不获取设备描述正文，不持久化 IP、完整 MAC、USN 或 LOCATION URL。AP 客户端隔离、Windows 防火墙和手机休眠会让该模式漏掉已连接设备；媒体服务广播只证明局域网存在服务端点，不证明它是电视，更不证明电视亮屏或播放。

设备类型百分比是透明规则的证据强度，不是统计模型给出的真实身份概率。人工标记只允许保存通用设备类别，不应填写人员姓名。随机 MAC、缺少服务广播和轮询间隔都会降低类型与使用情况的判断能力；页面必须保留理由、证据来源与限制说明。

“现场确认设备”由操作员人工维护，可以记录“电脑 1”“手机 1”等非身份化名称和设备状态，但不得写入人员姓名、账号、手机号或其他身份信息。人工台账不会自动与匿名网络信号绑定，避免把覆盖不完整的探测结果错误归因到具体设备。
